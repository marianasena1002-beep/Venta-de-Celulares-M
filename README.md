# 📱 INNOVA TECH

## 📌 Descripción

**Innova Tech** es una aplicación web orientada a la gestión de una tienda de celulares y dispositivos tecnológicos. El proyecto busca desarrollar una plataforma que permita administrar y organizar la información relacionada con los diferentes usuarios, productos y procesos de la tienda.

Actualmente, el proyecto cuenta con un sistema de acceso de usuarios mediante inicio de sesión, donde cada usuario puede ingresar de acuerdo con el rol que tiene asignado. Entre los roles se encuentran **administrador, empleado, cliente y proveedor**, permitiendo mostrar información y funcionalidades correspondientes a cada tipo de usuario.

El proyecto se encuentra en desarrollo y se continuará ampliando con nuevas funcionalidades para mejorar la gestión y experiencia de la tienda.
